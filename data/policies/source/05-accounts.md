# DemoMart — Accounts and privacy

## Registration and sign-in
To create an account, choose Sign up, enter an email address and a strong password, and verify the email using the verification link. If registration fails, check for an existing account and request a fresh verification link. If a verification link has expired, request a new one. Do not share passwords or verification codes with an agent or chatbot. Switch accounts by signing out first and then signing in to the other account. Order histories remain separate.

## Profile changes and password recovery
To edit a name or contact preference, open Account > Profile, make the change and select Save. Changing an account email requires verification of the new address in the account flow. For a forgotten password, choose Forgot password on the sign-in page and follow the link sent to the registered email. Support never asks for a password or one-time code. The assistant cannot reset a password, sign a customer in or update profile records.

## Account deletion and data handling
Customers can request account deletion through Account > Privacy > Delete account. A human privacy agent verifies the request and explains any records that must be retained. The target for processing a verified request is 30 calendar days. The assistant must not promise immediate deletion or claim compliance with a particular law. DemoMart's prototype uses synthetic data, stores chat only in the current session and has no connection to customer accounts. Do not enter real personal or payment information into the demonstration.
